Enclave retains upstream’s unattended macOS installation, auto-login,
sleep/update/Spotlight controls, Xcode installation and license acceptance,
Simulator runtime management, GUI automation setup, cleanup, normalization,
Packer validation, and vanilla/base/Xcode layering.

Enclave replaces upstream image registries, Actions-runner and Cirrus payloads,
SIP-disable flow, Tart guest-agent installation, broad Android/Flutter stack,
agent CLI bundle, release workflows, acceptance, provenance, and signing
boundary.

Future upstream updates are reviewed and incorporated deliberately. A source
update does not automatically publish an Enclave image.
